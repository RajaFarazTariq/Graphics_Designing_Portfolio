# Graphics Designing Portfolio 🎨

A stunning interactive 3D graphics portfolio showcasing creative design work and immersive web experiences built with cutting-edge web technologies.

## 🌟 Features

- **Interactive 3D Scenes**: Dynamic Three.js powered visualizations
- **Responsive Design**: Fully responsive and mobile-friendly interface
- **Modern UI/UX**: Clean, contemporary design aesthetic
- **Smooth Animations**: Engaging transitions and visual effects
- **Professional Portfolio**: Showcase of graphics design work
- **Fast Performance**: Optimized for quick loading and smooth interactions

## 🛠️ Technologies Used

- **Three.js** - 3D graphics library for WebGL rendering
- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with animations and transitions
- **JavaScript (ES6+)** - Interactive functionality and DOM manipulation
- **WebGL** - Hardware-accelerated graphics

## 🚀 Getting Started

### Prerequisites

- Web browser with WebGL support (Chrome, Firefox, Safari, Edge)
- Node.js (optional, for local development server)
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/RajaFarazTariq/Graphics_Designing_Portfolio.git
   cd Graphics_Designing_Portfolio
   ```

2. **Open in browser**
   - Option 1: Double-click `index.html` to open directly
   - Option 2: Use a local server (recommended)
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Python 2
     python -m SimpleHTTPServer 8000
     
     # Using Node.js (with http-server package)
     npm install -g http-server
     http-server
     ```

3. **View in browser**
   - Navigate to `http://localhost:8000` (or your server port)

## 💻 Usage

### Viewing the Portfolio

1. Open the application in a web browser
2. Explore the interactive 3D scenes
3. Navigate through different design projects
4. Use mouse/touch controls to interact with 3D elements
5. View detailed project information and descriptions

### Customization

To customize the portfolio for your own work:

1. **Update Project Information**
   - Edit `index.html` to add your project titles and descriptions
   - Update social links and contact information

2. **Add New Projects**
   - Add images to the `images/` folder
   - Create new Three.js scenes in `hero-scene.js` for additional 3D visualizations

3. **Modify Styling**
   - Edit `styles.css` to change colors, fonts, and layouts
   - Customize responsive breakpoints for different devices

4. **Enhance Interactivity**
   - Update JavaScript in `script.js` and `hero-scene.js`
   - Add event listeners for additional user interactions

## 🎯 Key Features Explained

### Three.js Integration
The portfolio uses Three.js for advanced 3D graphics rendering. The main scene configuration is handled in `hero-scene.js`, which sets up:
- WebGL renderer
- Camera perspectives
- Lighting and materials
- Geometry and mesh objects
- Animation loops

### Responsive Design
The CSS is optimized for all device sizes:
- Desktop (1920px and above)
- Laptop (1024px - 1920px)
- Tablet (768px - 1024px)
- Mobile (320px - 768px)

### Performance Optimization
- Minified Three.js library for faster loading
- Optimized image assets
- Efficient DOM manipulation
- CSS animations using GPU acceleration
